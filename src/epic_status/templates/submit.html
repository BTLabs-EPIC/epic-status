What gets checked

  • 1The host parses and is not already listed.
  • 2 It resolves to a public address. Private, loopback, link-local and reserved ranges are refused — otherwise this form would be a port scanner pointed at whatever somebody types.
  • 3 For a node: get_tip answers without credentials, and the height is close enough to the rest of the network to be this chain. The network is detected from the tip, not taken from your word for it.
  • 4 For a relay: the WebSocket handshake completes and the relay sends its Challenge frame. Nothing is written to your server and no address is subscribed.
  • 5 {{ probes_required }} successful checks, {{ probe_interval_s }}s apart. One success is luck.

One rule that will surprise you

An Epicbox hostname may contain only letters, digits and dots. A hyphen or an underscore is rejected here, and it is not pedantry: a hyphenated relay completes the handshake perfectly and would show green, while no wallet can parse an address on it, so no transaction could ever complete. Listing it would publish a permanently broken endpoint as healthy.

From a terminal

Which is how most operators will actually do it.

curl -X POST {{ site_url }}/api/v1/submit \
  -d kind=node \
  -d host=node.example.org:3413 \
  -d operator="Example Pool"

What is stored about you

A salted hash of your IP address, used only to stop one person flooding the queue. The salt is generated when the service starts and never written down, so the hashes cannot be reversed or linked across restarts even by whoever runs this instance.
